# This README file is located in the directory: arc_2d/Tensorboard_data

To visualize the TensorBoard logs in this directory, use the following command:

```bash
# Install TensorBoard if not already installed
pip install tensorboard

# Start TensorBoard and specify the log directory
tensorboard --logdir=. 
```

This will start a TensorBoard server, and you can access it in your browser at `http://localhost:6006`.
